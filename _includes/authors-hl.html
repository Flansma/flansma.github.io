{%- comment -%} Author list with the site owner's name underlined (.highlight-name). Usage: {% include authors-hl.html item=p %} Accepts any content item. `authors` may be a YAML list (publications, preprints) or a comma-separated string (legacy talk entries); solo talks with only `presenter` fall back to that. The owner's name comes from _data/profile.yml (`name.full`) — do not hardcode it. Placement: .highlight-name is unscoped CSS, so the underline works in any container. The one hard rule is that this must NOT sit inside an element carrying data-lang-* . On language switch i18n.js replaces that element's text nodes with the translated string; co-author names are bare text nodes, so they would all be deleted while the highlighted survived as an element. Put data-lang-* on an inner span that wraps only the translated text (see the venue span in index.html's PRESENTATIONS loop). {%- endcomment -%} {%- assign _authors = '' | split: '' -%} {%- if include.item.authors -%} {%- if include.item.authors.first -%} {%- assign _authors = include.item.authors -%} {%- else -%} {%- assign _authors = include.item.authors | split: ', ' -%} {%- endif -%} {%- elsif include.item.presenter -%} {%- assign _authors = include.item.presenter | split: ', ' -%} {%- endif -%} {%- assign _me = site.data.profile.name.full -%} {%- for a in _authors -%} {%- if a == _me -%}{{ a }}{%- else -%}{{ a }}{%- endif -%} {%- unless forloop.last %}, {% endunless -%} {%- endfor -%}
