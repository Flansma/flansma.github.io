{%- comment -%} Inline SVG icon. Replaces the Material Icons webfont, which cost 155 KB to render eight glyphs and rendered as literal words ("light_mode") until the cross-origin font arrived. Usage: {% include icon.html name="mail" %} {% include icon.html name=s.icon %} {% include icon.html name="light_mode" class="icon-light" %} Geometry is the official Material Icons Outlined 24px path data (github.com/google/material-design-icons, Apache 2.0) with the invisible bounding shape stripped. `fill="currentColor"` means colour is inherited, so callers only need to set size and colour. Decorative by default (aria-hidden="true"): every current call site sits in a control that already has its own aria-label, or next to visible text. Pass `label` when an icon is the only content of a control AND has no other label.
